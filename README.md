## 🚀 Featured Projects

### 🏠 ServiceHub — Home Services Booking Platform
> **Final Year Project** | React.js · Next.js · Node.js · MongoDB · Tailwind CSS · JWT

A production-grade **full-stack marketplace** connecting customers with home service providers (plumbing, electrical, cleaning, carpentry).

**Key Features:**
- 🔐 Secure **multi-role authentication** (Customer / Service Worker / Admin) with JWT + RBAC
- 💳 **Payment Gateway** + Cash on Delivery (COD) support
- 📋 Step-by-step booking flow with **OTP verification** & real-time status updates
- 📊 **Admin Dashboard** — manage workers, live bookings, disputes & revenue analytics
- 🗄️ MongoDB schema with Mongoose ODM — Users, Services, Bookings, Payments, Workers
